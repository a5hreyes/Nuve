Nuvé 💗

Tu espacio de inspiración

¿Qué es Nuvé?

Nuvé es un proyecto de una red social que nace con la idea de crear un espacio donde las personas puedan compartir sus gustos, ideas e inspiraciones. Es un lugar pensado para descubrir cosas nuevas, expresar la creatividad y encontrar contenido relacionado con diferentes intereses.

La página busca tener un ambiente agradable, con un diseño sencillo y bonito, donde los usuarios puedan explorar publicaciones, compartir sus propias ideas e interactuar con el contenido de los demás.

Este proyecto fue creado como parte de un trabajo de desarrollo web, poniendo en práctica los conocimientos adquiridos en HTML, CSS y JavaScript. Durante su desarrollo se buscó que no fuera solamente una página visual, sino que también tuviera diferentes apartados y elementos para explorar.

Objetivo del proyecto

El objetivo principal de Nuvé es desarrollar una plataforma donde compartir y descubrir contenido sea fácil y entretenido. Busca ofrecer un espacio en el que los usuarios puedan expresarse por medio de fotografías, videos, música y publicaciones sobre distintos temas.

También es una oportunidad para poner en práctica diferentes herramientas de programación, aprender cómo se construye una página web desde cero y combinar el diseño con elementos interactivos.

Principales características

Nuvé cuenta con diferentes apartados y opciones que permiten explorar y disfrutar del contenido de la página.

- Página de inicio: es el espacio principal donde se puede encontrar y explorar el contenido de Nuvé.
- Publicaciones: permite compartir ideas, pensamientos y contenido propio mediante textos y fotografías.
- Fotografías: cuenta con espacios para mostrar y compartir imágenes relacionadas con diferentes gustos e intereses.
- Videos: incluye un apartado para visualizar contenido audiovisual.
- Música: ofrece un espacio dedicado a la música, donde se puede disfrutar de diferentes canciones y contenido musical.
- Me gusta: permite reaccionar a las publicaciones y mostrar cuáles son las que más llaman la atención.
- Comentarios: permite escribir comentarios y compartir opiniones sobre las publicaciones.
- Filtros por categoría: ayuda a organizar el contenido y encontrar publicaciones de diferentes temas, como moda, belleza, peinados, música y comunidad.
- Publicaciones guardadas: permite marcar publicaciones de interés para encontrarlas fácilmente después.
- Eliminar publicaciones: permite quitar una publicación cuando ya no se desea mantener en la página.
- Perfil personal: cuenta con un espacio destinado al perfil del usuario.
- Modo claro y oscuro: permite cambiar entre dos apariencias diferentes para la página y mantiene guardada la preferencia seleccionada.
- Diseño adaptable: busca ofrecer una experiencia cómoda tanto en computadoras como en dispositivos móviles.

Tecnologías utilizadas

Para desarrollar Nuvé se utilizaron las siguientes tecnologías:

- HTML: se utilizó para organizar el contenido y crear la estructura de las páginas.
- CSS: se utilizó para darle diseño, colores, estilos y adaptar la página a diferentes tamaños de pantalla.
- JavaScript: se utilizó para agregar interactividad y hacer que diferentes funciones de la página trabajen correctamente.

Sobre el desarrollo

Nuvé es un proyecto que se ha ido construyendo poco a poco, probando diferentes ideas y agregando elementos para mejorar la experiencia de la página.

Durante este proceso se han puesto en práctica conocimientos de programación, diseño web y organización de archivos. También ha sido una oportunidad para aprender a resolver errores, mejorar el código y comprender cómo se relacionan HTML, CSS y JavaScript.

El proyecto representa todo el trabajo y el aprendizaje que hay detrás de la creación de una página web, además de ser una oportunidad para seguir experimentando con nuevas ideas y mejorar sus características.
